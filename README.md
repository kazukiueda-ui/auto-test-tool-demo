# Auto-test-tool デモ（モック）

**Auto-test-tool**（N vs N+1 回帰比較ツール）の実行〜AIレビューを再現した**静的デモ**です。
API・ブラウザ自動化・サーバは不要で、`index.html` を開くだけで動きます（結果は下記比較用に用意した固定データを再生）。

## 対象アプリ
同じ ToDo アプリの「正常版」と「セキュリティパッチで不具合が混入した版」を比較します。
- 修正前 N（正常版）: https://uedakazuki-plainliving.github.io/auto-test-site-demo/normal/
- 修正後 N+1（パッチ版・不具合入り）: https://uedakazuki-plainliving.github.io/auto-test-site-demo/patched/

## 再現している内容
「▶ デモを実行」を押すと、実ツールと同じ流れ（捜索 → 再実行 → 比較 → AIレビュー）を再生します。

- **⑤ N vs N+1 比較ダッシュボード**：全10ケース中 **7 PASS / 3 DIFF（一致率70%）**。パッチ版で混入した3つの回帰を検出：
  1. **未完了フィルタの反転**（不具合3）… `diff-structure`
  2. **記号除去でアポストロフィが消える**（不具合1）… `diff-structure`
  3. **二重エスケープで `&amp;` が露出**（不具合2）… `diff-visual`
  各 DIFF は N / N+1 の具体テキストと原因を表示します。
- **🗺 仕様の画面遷移図 × 1回目走査の比較**：Mermaid の画面(ノード)・遷移(エッジ)を走査が踏破できたかを表示（本デモは 7/7・6/6＝100%）。
- **② AIレビュー（4観点＋合議）**：網羅／リスク／利用者／敵対的の4観点スコア＋合議の総合評価・優先度つき改善アクション（本デモは**固定のモック応答**。実運用では Claude API を使用）。

## 使い方 / 公開
- ローカル: `index.html` をブラウザで開く（または `python -m http.server` などで配信）。
- GitHub Pages: 本リポジトリを push し、Settings → Pages でルート公開すれば URL で共有できます。

## 注意
- これは**デモ用モック**です。結果は上記 normal/patched の比較に合わせた固定データで、実際に対象サイトへアクセスしたり AI を呼び出したりはしません。
- 本体ツール（実際に走査・比較・LLMレビューを行う版）は別リポジトリです。
